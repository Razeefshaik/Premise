# Kestrel Platform (fictional)

This repository is a synthetic company used to demonstrate Premise at WeMakeDevs x FalkorDB Graph Hacks.
Kestrel, Paylane, and every person named here are fictional. The service topology follows Google's
Online Boutique demo (Apache 2.0); `webhookingress` and `refundworker` are fictional additions.

Decisions live in `adr/`. Each ADR declares the guarantees it provides, the guarantees it relies on,
and the assumptions those guarantees require. Checkable assumptions are predicates over facts listed in
`facts.yaml`. Manual assumptions carry an attestation by a person, with a review date.
