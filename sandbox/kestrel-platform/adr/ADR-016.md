# ADR-016: Mute Paylane delivery failure alerts

## Context
Paylane sends a delivery failure alert whenever a webhook times out and it schedules a retry.
Following ADR-007, webhookingress acknowledges every webhook within the timeout, so these alerts are noise
from retries we never cause.

## Decision
Route Paylane delivery failure alerts to a low priority channel.

## Consequences
If our acknowledgement ever became slower than Paylane's timeout, real failures would be missed.
