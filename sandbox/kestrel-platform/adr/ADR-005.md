# ADR-005: Store cart sessions in Redis

## Context
cartservice needs fast reads of the current basket.

## Decision
Keep sessions in Redis with an expiry.

## Consequences
Old sessions disappear automatically. Nobody has yet written down which promise depends on the expiry.
