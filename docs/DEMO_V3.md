# Three-minute V3 walkthrough

Use the local app for arbitrary checks, or build the explicitly labelled static replay
using [REPLAY.md](REPLAY.md). The replay has recorded selections and no live API.
No public deployment or narrated demo video has been produced by this build.

The README GIF contains three real browser captures, not a full demo recording. Keep the
replay banner visible when demonstrating saved results. The UI does not claim that an LLM
performed the deterministic checks or that the benchmark establishes general QA accuracy.
